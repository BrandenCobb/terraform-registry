# Examples

- [`docker-compose/`](docker-compose/) — local/single-host deployment with persistent storage
- [`kubernetes/`](kubernetes/) — single-replica PVC deployment
- [`terraform-config/`](terraform-config/) — provider network-mirror CLI configuration
- [`filesystem/`](filesystem/) — filesystem layout reference

The current product supports filesystem storage only and is single-writer. Old S3 and multi-replica examples are intentionally not supported.
