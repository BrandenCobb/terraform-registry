# Terraform Registry Examples

This directory contains practical examples for using the Terraform Registry.

## Examples

### [filesystem/](filesystem/)
Running the registry with filesystem storage (local development)

### [s3/](s3/)
Running the registry with S3 storage (production)

### [kubernetes/](kubernetes/)
Deploying the registry to Kubernetes

### [docker-compose/](docker-compose/)
Running the registry with Docker Compose

## Quick Start

Choose an example based on your deployment scenario:

- **Local development** → Use [filesystem/](filesystem/)
- **AWS production** → Use [s3/](s3/)
- **Kubernetes cluster** → Use [kubernetes/](kubernetes/)
- **Docker environment** → Use [docker-compose/](docker-compose/)

Each example includes:
- Complete configuration files
- Step-by-step setup instructions
- Usage examples with Terraform
- Troubleshooting tips
